# node-aws-stack

Agentic app template: Express plus TypeScript plus Postgres plus BullMQ on
Node, Docker Compose everywhere, Terraform-managed AWS (EC2 plus RDS plus S3).

Start here: [`AGENTS.md`](AGENTS.md) — it tells your coding agent (Claude Code,
Muse, Codex, Cursor, OpenCode, and anything else that reads `AGENTS.md`) how
to plan, build, launch, and tear down projects on this stack. Nothing is built
yet; the repo is process plus stack definition.
